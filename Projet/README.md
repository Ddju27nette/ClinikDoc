# Projet 1 : Prise de rendez-vous dans une clinique (ClinikDoc)
**Groupe 01** - Filière Génie Informatique (ENSPD)

Application web de gestion des consultations médicales permettant la réservation en ligne de créneaux sans doublon et le pilotage du planning pour une clinique privée de Douala.

---

## 1. Installation

Ouvrez un terminal dans le dossier `projet/` et exécutez les commandes suivantes :

```bash
# Création de l'environnement virtuel
python -m venv venv

# Activation de l'environnement virtuel
# Sur Windows :
venv\Scripts\activate
# Sur Linux / macOS :
source venv/bin/activate

# Installation des dépendances
pip install -r requirements.txt
